# Правила роботи з Git

## Повідомлення комітів

Формат: `prefix: short description`.

- `spec:` — зміни задуму та вимог системи.
- `test:` — додавання або зміна тестів.
- `feat:` — реалізація функціональності.
- `docs:` — документація та журнали роботи.
- `gate:` — рішення контрольних точок.

Повідомлення мають коротко пояснювати зміст зміни.

## Гілки

`main` — основна гілка з перевіреними змінами.
Для окремих завдань створюються короткочасні гілки.
Після перевірки їхні зміни зливаються в `main`.

## Зміни агента

Зміни Codex перевіряються через `git diff` перед додаванням до індексу.
Авторство змін і причина їх прийняття фіксуються в `logs`.
