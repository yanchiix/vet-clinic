# Вирішення конфлікту людина–агент

## Причина конфлікту

У двох гілках змінено той самий рядок у spec/vision.md:

- agent/clarify-owner, коміт 0cfe357: Codex уточнив, що клієнт
  може мати одну або кілька тварин. Зміну перевірено через git diff.
- human/single-pet, коміт a99f3cc: вручну додано обмеження
  «лише одна тварина» для навчального моделювання конфлікту.

Під час злиття agent/clarify-owner у human/single-pet
Git повідомив про конфлікт вмісту.

## Еталон і рішення

Спільного предка знайдено командою git merge-base.
У spec/vision.md з коміту 03ea620 клієнт описаний як власник
однієї або кількох тварин.

Залишено формулювання, яке дозволяє клієнту мати одну або
кілька тварин. Обмеження однією твариною відхилено, оскільки
воно суперечить початковому задуму.

Рішення ґрунтується на змісті вимоги, а не на авторстві
чи часі створення зміни.

## Питання для ЛР2

Для вирішення цього конфлікту початкового задуму достатньо.
Окремо потрібно уточнити, чи може клієнт зареєструватися
до додавання першої тварини.
