# Кодинговий агент

**Інструмент:** OpenAI Codex.

**Клас:** ШІ-агент для розробки програмного забезпечення.

**Доступ до репозиторію:** через розширення Codex у VS Code, де відкрито локальний репозиторій `vet-clinic`.

**Операції:** читання й аналіз файлів, створення та редагування файлів, виконання команд і запуск тестів у межах наданих дозволів.
