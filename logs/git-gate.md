# GIT-GATE: ЛР1

## Рішення

Репозиторій готовий до переходу до наступного етапу.

## Перевірки

- Створено структуру SDD: spec/, tests/, src/, docs/ і logs/.
- Зафіксовано початковий задум системи та правила роботи з Git.
- Codex проаналізував структуру проєкту й змінив spec/vision.md.
- Зміну Codex перевірено людиною через git diff.
- Змодельовано конфлікт між ручною зміною та зміною Codex.
- Конфлікт вирішено за початковим задумом системи.
- Робоче дерево Git чисте.

## Питання для ЛР2

Потрібно уточнити, чи може клієнт зареєструватися до додавання першої тварини.
